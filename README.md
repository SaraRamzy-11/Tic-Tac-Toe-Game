Tic-Tac-Toe Game 🎮

A simple interactive Tic-Tac-Toe game built using C# and Windows Forms as part of the ProgrammingAdvices learning roadmap.

📌 About the Project

This project is a desktop implementation of the classic Tic-Tac-Toe game. It allows two players to take turns, tracks the game state, and displays the winner when a player completes a winning combination.

✨ Features

- Interactive 3×3 game board.
- Two-player gameplay (X and O).
- Turn tracking.
- Winner detection.
- Game over status.
- Restart Game functionality.

🛠️ Technologies Used

- C#
- .NET Framework
- Windows Forms
- Visual Studio
